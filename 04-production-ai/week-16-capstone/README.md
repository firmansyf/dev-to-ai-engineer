# Minggu 16: Capstone

> **Fase 4: Production AI** · [⬅ Minggu 15](../week-15-deployment/) · [Kurikulum](../../README.md)

Minggu terakhir adalah waktu untuk menggabungkan semua yang sudah Anda pelajari menjadi satu aplikasi AI yang utuh, dapat dipakai, dan siap dipamerkan di portofolio.

## Tujuan belajar

Setelah minggu ini, Anda dapat:

- Merancang aplikasi AI dari problem nyata hingga solusi yang ter-deploy.
- Mengambil keputusan arsitektur (model, retrieval, tool, workflow vs agent) dan menjelaskan alasannya.
- Menunjukkan kualitas aplikasi dengan data eval, bukan sekadar demo.
- Mendokumentasikan dan mempresentasikan project secara profesional.

## Topik

- Memilih problem: sempit, nyata, dan bisa dievaluasi
- Menulis design doc singkat: problem, pengguna, arsitektur, risiko, dan metrik keberhasilan
- Scope management: MVP dulu, baru fitur tambahan
- Menulis README dan arsitektur untuk portofolio
- Retrospektif: apa yang berhasil, apa yang akan Anda lakukan berbeda, dan apa yang ingin dipelajari selanjutnya

## Latihan

1. **Design doc.** Tulis design doc 1–2 halaman sebelum mulai coding, lalu minta masukan dari orang lain (mis. lewat issue atau diskusi di repo ini).
2. **Retrospektif.** Di akhir minggu, tulis retrospektif tentang 16 minggu Anda: progres, kesulitan, dan rencana berikutnya.

## 🏁 Milestone 4: Aplikasi AI di production

Bangun aplikasi AI end-to-end untuk problem yang Anda pilih sendiri. Anda boleh melanjutkan Milestone 3 atau memulai dari awal.

**Persyaratan minimum:**

- Menyelesaikan problem nyata untuk pengguna yang jelas, dan dijelaskan di README.
- Memakai minimal dua dari: structured output, RAG, tool use/agent, atau model ML buatan sendiri.
- Eval dataset (minimal 30 kasus) dan laporan hasil eval.
- Observability: logging/tracing serta pencatatan biaya dan latensi.
- Guardrail dasar dan test untuk kasus keamanan (prompt injection).
- Ter-deploy dan bisa diakses publik, dengan CI/CD yang menjalankan lint, test, dan eval.
- README portofolio: demo (screenshot/GIF/video), diagram arsitektur, keputusan desain, hasil eval, keterbatasan, dan langkah selanjutnya.

**Bonus:** bagikan project Anda dengan membuka PR yang menambahkan link-nya ke bagian showcase di README utama.
